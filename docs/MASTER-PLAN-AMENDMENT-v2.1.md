# Master Plan Amendment v2.1 — File 22 and File 23

**Date:** 28 July 2026  
**Affected parent document:** Sabri Social Homeopathy Platform — Comprehensive Master Plan v2.0

## Prior rule

File 22 was assigned to “Complete Public UI, Profile Timeline and Visual Experience.”

## New governing rule

- **File 22:** Sabri Universal Post Composer.
- **File 23:** Complete Public UI, Profile Timeline and Visual Experience.

## Reason

A single role-aware creation gateway and adapter contract must be established before the final public profile and timeline visual layer is completed.

## Ownership impact

File 22 does not take permanent ownership from File 21 or any native module. File 23 remains responsible for final public profile/timeline presentation, while File 21 retains native social publication ownership and timeline data contracts.

## Migration impact

- roadmap references to the former File 22 move to File 23;
- package names, repository names, and release manifests identify Universal Post Composer as File 22;
- existing hook names are preserved until compatibility aliases and tests exist;
- no runtime content is migrated solely because of this numbering change.

## Test impact

Documentation, repositories, package manifests, integration maps, and staging checklists must consistently apply the amended numbering.
