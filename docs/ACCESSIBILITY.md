# Accessibility

Target: WCAG 2.2 AA design objective.

Required acceptance includes semantic headings, visible labels, keyboard operation, focus management, screen-reader announcements, non-color-only validation, reduced motion, sufficient contrast, 44px touch targets, no keyboard traps, accessible upload progress, and captions or transcripts where media applies.

The Create selector uses links with labels and descriptions rather than inactive JavaScript-only buttons. Generated heading IDs are unique when the shortcode appears more than once.

Acceptance viewports: 320, 360, 390, 480, 768, 900, 1024, 1100, 1280, 1366, 1440, 1600, and 1920 pixels.

Acceptance also covers 200% and 400% zoom, forced colors and high contrast, mixed RTL/LTR content, Chrome, Edge, Firefox, Safari, representative Android and iOS devices, slow connections, and a no-JavaScript fallback for routing.
