# Staging Acceptance

Before merge or package promotion:

- verified backup and rollback proof;
- File 00 version and permission API recognized;
- File 20 official Create visibility hook recognized;
- Create page mapped without duplicate or overwritten pages;
- logged-out page is noindex/no-cache and offers safe login;
- Founder/Admin authorized route;
- approved verified doctor route according to adapter policy;
- suspended, rejected, patient, student, and unauthorized accounts denied;
- one broken adapter does not break healthy adapters or the header;
- invalid, duplicate, and API-incompatible keys produce diagnostics;
- deterministic adapter order;
- no inactive buttons or dead links;
- desktop and mobile Create outputs agree;
- Safe Mode hides creation without affecting public reading;
- PHP 8.1, 8.2, and 8.3 checks green;
- WordPress coding standards, PHPStan, and PHPUnit green;
- no horizontal overflow and keyboard-only acceptance;
- no public preview, draft, diagnostic, or sensitive-data leakage.

No live deployment is authorized by automated checks alone.
