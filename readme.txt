Universal, role-aware creation gateway for the Sabri Social Homeopathy Platform.

== Description ==

File 22 unifies authorized content-creation workflows without taking canonical ownership from native modules. Permanent content, durable native drafts, moderation, secure media, patient consent, identity evidence, clinical records, publication history, search/ranking truth, notifications and canonical URLs remain with their designated owners.

Version 1.0.0-rc.3 reconciles the current consolidated central plan and the current File 22 plan in one repository source candidate. It combines the plan-complete browser Composer with the newer governance/lifecycle contracts, four-dimensional state model, Patient Case/common safety holds, correction/revision/scheduling delegation, optional adapter packs, File 26 search projection boundary and the current Sabri Green fallback while preserving File 25 as visual-token owner.

File 22 never persists draft bodies, patient consent evidence, identity evidence or media bytes in its session/submission/outbox stores. The browser client does not use localStorage, sessionStorage or IndexedDB for draft content. Private surfaces are authenticated, nonce-protected, owner-scoped, no-store, noindex, bounded and reauthorized on each operation.

The current central-plan business boundary is also fail-closed: File 22 contains no Free/Pro/Premium paywall, PKR 400 core gate, paid-AI entitlement, donor ranking, donor reach or donor feature advantage.

Mandatory platform dependencies for this candidate:

* Sabri Membership Core plugin 1.2.3 or later;
* File 00 database schema 1.2.0 or later;
* File 00 public contract 1.1.2 or later;
* File 20 Create contract compatibility anchor 1.0.1;
* File 21 compatible publishing provider/package as verified on the target staging environment.
